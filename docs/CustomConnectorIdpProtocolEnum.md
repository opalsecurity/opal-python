# CustomConnectorIdpProtocolEnum

How Opal reads users from the Custom Connector when it is an upstream directory: `OPAL` for Opal's custom connector API, or `SCIM` for a SCIM 2.0 server, authenticated with the signing secret as a bearer token. Defaults to `OPAL`.

## Enum

* `OPAL` (value: `'OPAL'`)

* `SCIM` (value: `'SCIM'`)
