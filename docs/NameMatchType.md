# NameMatchType

How to match a free-text name filter on list endpoints. All match types are case-insensitive. When omitted, CONTAINS is used. REGEX is not supported here — use POST /queries/run for regular-expression matching.

## Enum

* `CONTAINS` (value: `'CONTAINS'`)

* `EQUALS` (value: `'EQUALS'`)

* `STARTS_WITH` (value: `'STARTS_WITH'`)

* `ENDS_WITH` (value: `'ENDS_WITH'`)
