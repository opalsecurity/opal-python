# PaladinContextSourceKind

The kind of source a Paladin can read. A SLACK_CHANNEL is a Slack channel; a DOCUMENT is a Notion or Confluence page.

## Enum

* `SLACK_CHANNEL` (value: `'SLACK_CHANNEL'`)

* `DOCUMENT` (value: `'DOCUMENT'`)
